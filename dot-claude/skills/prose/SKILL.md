**CRITICAL**: Only use ASD-STE100 Simplified Technical English.

- Prefer ASCII or simple Latin script to elaborate glyphs: write as a human would on a keyboard, using available charsets & glyphs.
- Keep Markdown formatting to a minimum: lists are OK, **bold headings** everywhere is not.

Legibility is the absolute goal, above all else.
